# Hyprland Keybindings Guide

> **Note:** The **`SUPER`** key is your `$mainMod` (typically the Windows/Command key), and **`ALT`** is your `$altMod`.

### 🚀 Core Applications
| Keybind | Action |
| --- | --- |
| `SUPER + Return` | Open Terminal |
| `SUPER + W` | Open Browser |
| `SUPER + SHIFT + W` | Open Browser (Incognito) |
| `SUPER + E` | Open File Manager (`lf`) |
| `SUPER + N` | Open RSS Reader (`newsboat`) |
| `SUPER + grave` (\`) | Emoji Picker (`bemoji`) |

### 🪟 Window Management
| Keybind | Action |
| --- | --- |
| `SUPER + Q` | Close Active Window |
| `SUPER + SHIFT + Q` | Exit Hyprland |
| `SUPER + F` | Toggle Floating |
| `SUPER + M` | Toggle Fullscreen |
| `SUPER + BackSpace` | Power/System Actions Menu (`sysact`) |
| `SUPER + S` | Pin Window |
| `SUPER + B` | Toggle Waybar |
| `SUPER + Space` | Swap Window with Master |
| `ALT + Tab` | Cycle Focus (Windows-style behavior) |
| `SUPER + Left Click` | Move Window (Drag) |
| `SUPER + Right Click` | Resize Window (Drag) |

### 🏗️ Layout Controls
| Keybind | Action |
| --- | --- |
| `SUPER + T` | Switch to Master Layout |
| `SUPER + Y` | Switch to Dwindle Layout |
| `SUPER + J` | Focus Next Window |
| `SUPER + K` | Focus Previous Window |
| `SUPER + H` | Shrink Window Width |
| `SUPER + L` | Grow Window Width |
| `SUPER + I` / `O` | Add Window to Master Area |
| `SUPER + SHIFT + O` | Remove Window from Master Area |

### 🪄 Scratchpads (Hidden Drop-down Windows)
| Keybind | Action |
| --- | --- |
| `SUPER + SHIFT + Return`| Terminal Scratchpad |
| `SUPER + C` | Calculator Scratchpad (`bc`) |
| `SUPER + V` | Audio Mixer Scratchpad (`pulsemixer`) |
| `ALT + M` | Music Player Scratchpad (`ncmpcpp`) |
| `ALT + S` | Spotify Apps Scratchpad (Brave Web App) |
| `ALT + W` | WhatsApp Scratchpad (Brave Web App) |
| `SUPER + SHIFT + S` | Send active window to terminal scratchpad silently |

### 📸 Screenshots & Recording
| Keybind | Action |
| --- | --- |
| `Print` | Capture Screen to Clipboard |
| `SHIFT + Print` | Capture Region to Clipboard |
| `ALT + Print` | Capture Region to Clipboard |
| `SUPER + Print` | Toggle Screen Recording |
| `SUPER + SHIFT + Print` | Toggle Region Screen Recording |
| `SUPER + Delete` | Stop Screen Recording |

### 🖥️ Workspaces
| Keybind | Action |
| --- | --- |
| `SUPER + 1-9` | Switch to Workspace 1-9 |
| `SUPER + SHIFT + 1-9` | Move Window to Workspace 1-9 |
| `SUPER + G` / `;` | Switch to Previous / Next Workspace |
| `SUPER + SHIFT + G` / `;`| Move Window to Prev / Next Workspace |
